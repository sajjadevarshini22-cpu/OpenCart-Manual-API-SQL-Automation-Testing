# OpenCart Manual, API, SQL and Automation Testing Project

## Project Overview
This project demonstrates end-to-end QA testing practice on the OpenCart e-commerce application. It includes manual testing concepts, API testing using Postman, SQL database validation, and Selenium Java TestNG automation.

## Application Under Test
OpenCart - E-Commerce Platform

## Testing Types Covered
- Functional Testing
- Smoke Testing
- Sanity Testing
- Regression Testing
- Negative Testing
- API Testing
- Database Testing
- Basic Automation Testing

## Modules Tested
- User Registration
- Login
- Product Search
- Product Details
- Cart
- Checkout
- Order Flow
- Order History

## Key Testing Activities
- Designed and executed test scenarios for OpenCart e-commerce workflows.
- Validated API requests and responses using Postman.
- Verified status codes, request payloads, and JSON response data.
- Performed SQL validation for customer, product, cart, and order-related data.
- Automated important functional flows using Selenium Java and TestNG.
- Practiced end-to-end QA project documentation.
